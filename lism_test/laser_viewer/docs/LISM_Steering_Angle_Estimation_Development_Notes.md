# LISM Steering Angle Estimation Development Notes

## Purpose

This document records the current architecture, operating behavior, calibration approach, timing assumptions, sensor ownership model, validity handling, timeout behavior, and future development direction for real-time laser steering angle estimation using two LISM line sensors.

The steering estimator consumes position measurements generated by the laser detector and computes a beam angle using the measured position difference between two physically separated sensors.

The current system is designed for operation with a pulsed LAP laser and must tolerate intermittent valid detections while still identifying true sensor failures and stale measurements.

```text
          Top Sensor
               |
               |
               |
               | 230 mm
               |
               |
               |
        Bottom Sensor
```

Measured positions:

```text
top_mm
bottom_mm
```

Angle:

```text
angle_deg =
    atan(
        (bottom_mm - top_mm)
        /
        separation_mm
    )
```

Current implementation:

```python
angle = math.degrees(
    math.atan2(
        bottom_mm - top_mm,
        separation_mm
    )
)
```

# Important Discovery

## Original Assumption

The original implementation assumed steering should only be calculated from a fresh measurement pair.

## Observed Reality

Testing with the LAP laser revealed intermittent valid detections.

```text
NO_REGIONS
NO_REGIONS
NO_REGIONS
VALID
NO_REGIONS
NO_REGIONS
```

Most incoming camera frames do not contain a valid laser region.

## Root Cause

The LAP system is not producing a continuously visible target.

Observed modulation:

```text
49.63 Hz
```

Observed period:

```text
20.15 ms
```

As a result, most camera frames contain no laser while some contain a valid crossing.

# Steering Ownership Model

## Current Model

```text
Top sensor owns:
    latest valid top measurement

Bottom sensor owns:
    latest valid bottom measurement
```

Invalid frames do not replace valid measurements.

## Measurement Update Rule

Valid measurements update the corresponding cached measurement.

## Invalid Measurement Rule

Invalid measurements are ignored and do not erase valid state.


Each cached measurement contains:

```text
pixel position
timestamp
```

## Angle Computation

Whenever a measurement arrives:

```python
update(measurement)
```

The estimator:

1. Updates the relevant cache if valid.
2. Checks freshness.
3. Computes angle if both measurements remain fresh.

# Timeout Architecture

## Purpose

Timeouts exist to detect:

- Sensor failure
- Camera disconnect
- Optical failure
- Laser loss
- Detector malfunction
- Excessively stale data

## Current Timeout

Current experimental value:

```python
maximum_measurement_age_ms = 1000
```

## Invalid Conditions

```text
top_missing
bottom_missing
top_timeout
bottom_timeout
```

---

# Why Pairing Was Removed

The previous system depended on timestamp pairing.

The available information that matters is:

```text
Latest valid top position
Latest valid bottom position
```

not:

```text
Latest matched frame pair
```

The steering estimator therefore no longer depends on pair matching.

---

# Expected Behavior

## Normal Operation

Intermittent valid detections should still produce a valid angle while both cached measurements remain fresh.

## Sensor Failure

A disconnected or failed sensor should eventually produce:

```text
top_timeout
```

or:

```text
bottom_timeout
```

and invalidate the angle.

# Safety Requirements

A steering angle must not:

```text
Start motion
Resume motion
Clear faults
Override E-stop
Override interlocks
```

A fresh valid measurement must be received before the angle may be considered current after recovery.

```text

2. Continue using timeout validity.
3. Keep pair-age logic removed.
4. Run steering-angle validation tests.
5. Verify sign convention.
6. Verify calibration scale.
7. Measure normal top/bottom measurement age.
8. Move timeout into configuration.
9. Integrate steering publication.

```

The current working principle is:

> Steering angle should be calculated from the most recent valid top measurement and the most recent valid bottom measurement. Invalid frames must not erase valid data. Steering remains valid while both measurements remain fresh and becomes invalid only when a sensor times out, is missing, or otherwise ceases providing sufficiently recent data.
